# Reutilizar skill code_review

## Resumo curto
Roteamento aprendido para reutilizar a skill code_review antes de RAG/LLM.

## Quando usar
Quando a tarefa atual combina com exemplos anteriores que foram resolvidos por essa skill.

## Instrucoes
Consultar e executar a skill code_review; se falhar, continuar o pipeline cognitivo normal.

## Acao reutilizavel
- action_kind: skill_code_review
- status: promoted
- confidence: 0.600

## Exemplos observados
- Traduza a frase 'O céu é azul' para o idioma de código 4.
- Traduza a frase 'O céu é azul' para o idioma de código 17.
